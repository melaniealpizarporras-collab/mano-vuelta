# Mano Vuelta — Prototipo UINNOVA

Prototipo web demostrativo para el proyecto Mano Vuelta.

## Ejecutar
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar
1. Subir `app.py` y `requirements.txt` a un repositorio público de GitHub.
2. Entrar a Streamlit Community Cloud.
3. Crear una app desde el repositorio.
4. Seleccionar `app.py` como Main file.
5. Deploy.
